# PlateShare 🍕

Leftover food sharing for campus. Clubs and dining halls post extra food after events, students claim a serving and pick it up.

## Features
- Browse live listings with building, dietary and pickup-time filters
- Search and sort listings
- Claim a serving (20 min pickup window) and cancel if plans change
- Post your own leftovers
- Leaderboard of top sharers

## Running it
No build step. Open `index.html` in a browser.
